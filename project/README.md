# My personal website
#### Video Demo:  <https://youtu.be/Kw8kIXrJyHg?si=yhbVozsretRkmU8v>
#### Description: Built using HTML5, custom CSS3, and modern icon frameworks Bootstrap and Font Awesome), this responsive, multi-page personal portfolio serves as a centralized hub to present my academic achievements, leadership experience, and professional background. The website features an intuitive design structured across seven dedicated pages: a bio and contact landing page `index.html`, an educational timeline linked directly to Minerva University `education.html`, an interactive showcase of high school activities complete with contextual photography and program links `extracurricular.html`, an organized gallery of earned qualifications `certificates.html`, an easily downloadable CV equipped with a direct PDF link for recruitment reviews `cv.html`, and a media gallery documenting my participation in professional summer programs. Optimized for visual consistency and seamless user navigation, the site leverages a centralized stylesheet `styles.css` for fine-tuned layout control—incorporating precise margin spacing, custom typography, image dimensioning, and absolute positioning—while organizing all underlying assets, images, and documents cleanly within the root directory.
